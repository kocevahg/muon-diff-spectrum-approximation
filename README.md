# Сравнение параметризаций дифференциального спектра атмосферных мюонов

Проект предназначен для воспроизводимого сравнения нескольких
аналитических параметризаций дифференциального спектра атмосферных
мюонов с экспериментальными данными. Он загружает наборы из SQLite-базы,
применяет единые правила отбора, выполняет взвешенные подгонки,
сравнивает модели по `χ²/dof` и исследует области применимости
параметризаций.

## Структура проекта

``` text
project/
├── models.py
├── pipeline.py
├── figures.py
├── explore.py
└── out/
```

1.  **Математические модели** - реализация пяти аналитических
    параметризаций спектра:

    -   Гайссер;
    -   Танг;
    -   Шукла;
    -   Рейна;
    -   Богданова

2.  **Основной pipeline** - единая обработка базы данных:

    -   загрузка данных из `muon_data.db`;
    -   формирование наборов вида `(experiment, theta_center)`;
    -   применение правил отбора A/B/B85/C;
    -   обработка нулевых/отсутствующих ошибок;
    -   подгонка всех моделей;
    -   расчёт `χ²/dof`;
    -   построение рейтингов и диагностик.

3.  **Разведочный анализ** - отдельный скрипт `explore.py` для
    просмотра подгонок отдельных наборов, параметров с погрешностями,
    невязок и сравнения с опубликованными коэффициентами.

### `models.py`

Содержит аналитические формы спектра и связанные с ними константы,
начальные значения, границы параметров, опубликованные коэффициенты и
области применимости.

Все основные функции имеют явные аргументы `p` и `theta`;

Единицы интенсивности:

``` text
см⁻² с⁻¹ ср⁻¹ (ГэВ/c)⁻¹
```

### `pipeline.py`

Выполняет подгонку моделей к
каждому набору данных, строит рейтинги и диагностику.

Основная статистика сравнения - `χ²/dof`:

-   медиана `χ²/dof` по наборам;
-   глобальное `Σχ² / Σdof`.

### `explore.py`

Интерактивно-настраиваемый разведочный скрипт. 
Он использует те же модели, начальные значения, границы и правила
подгонки, что и `pipeline.py`, но дополнительно сохраняет ковариационную
матрицу и вычисляет погрешности параметров.

# Входные данные

Основной источник данных - SQLite-база `muon_data.db`.

Скрипт `pipeline.py` ожидает таблицу `muon_data` со следующими полями:

| Поле           | Назначение                           |
|----------------|--------------------------------------|
| `experiment`   | название эксперимента                |
| `theta_center` | зенитный угол θ, °                   |
| `momentum`     | импульс, ГэВ/c                       |
| `intensity`    | интенсивность, см⁻² с⁻¹ ср⁻¹ (ГэВ/c)⁻¹|
| `total_error`  | полная погрешность интенсивности     |

SQL-запрос, используемый pipeline:

``` sql
SELECT
    experiment,
    theta_center AS angle,
    momentum,
    intensity,
    total_error AS error
FROM muon_data
ORDER BY experiment, theta_center, momentum;
```

Набор данных определяется как пара:

``` text
(experiment, theta_center)
```

## Обработка ошибок

Если `total_error` отсутствует, не является конечным числом или не
положителен, используется резервная оценка:

``` text
σ = 0.10 · I
```

То есть ошибка принимается равной 10% интенсивности.

В `pipeline.py` определены четыре группы дополняющих друг друга наборов,
которые объединяются по импульсу:

``` text
OKAYAMA + L3+C, θ ≈ 30°
Nottingham + Kellogg, θ ≈ 30°
Nottingham + L3+C, θ ≈ 45°
MUTRON + DEIS, θ ≈ 88°
```

Допуск поиска соответствующего угла:

``` text

```

После объединения точки сортируются по импульсу, а результирующий угол
принимается равным среднему углу входящих наборов.

Если требуется анализировать исходные записи без такого объединения,
соответствующую логику необходимо изменить в `load_datasets()` /
`merge_datasets()`.

# Математические модели

## 1. Гайссер

Асимптотическая модель, не учитывающая кривизну атмосферы и распад мюона.

$$
I(p) = A_G \cdot p^{-\gamma} \cdot \left[ \frac{1}{1 + \frac{1.1 \cdot p \cdot \cos\theta}{\varepsilon_\pi}} + \frac{0.054}{1 + \frac{1.1 \cdot p \cdot \cos\theta}{\varepsilon_K}} \right]
$$

- **Свободные параметры:** $A_G$ (нормировка), $\gamma$ (показатель)
- **Константы:** $\varepsilon_\pi = 115$ ГэВ, $\varepsilon_K = 850$ ГэВ
- **Заявленная область:** $p \gtrsim 100/\cos\theta$ ГэВ/c, $\theta \lesssim 70^\circ$

---
## 2. Танг

Модифицированная модель Гайссера с учётом сферической атмосферы и низкоэнергетических поправок. Используется эффективный $\cos\theta^*$, рассчитанный с помощью CORSIKA.

$$
I(p) =
A_T \cdot 0.14 \cdot A \cdot p_w^{-\gamma} \cdot \Phi(p,\theta)
$$

где

$$
\Phi(p,\theta) = \frac{1}{1 + \frac{1.1 \cdot p_t \cdot \cos\theta^{\ast}}{\varepsilon_{\pi}}} + \frac{0.054}{1 + \frac{1.1 \cdot p_t \cdot \cos\theta^{\ast}}{\varepsilon_K}} + r_c
$$

Модифицированный импульсы:

$$
p_w = \begin{cases}
\frac{3p + 7/\cos\theta^{\ast}}{10}, & \text{при } p \le 1/\cos\theta^{\ast} \\
p, & \text{иначе}
\end{cases}
$$

$$
p_t = \begin{cases}
p_w , & \text{при } p > 100/\cos\theta^{\ast} \\
p_w + \Delta, & \text{иначе}
\end{cases}
$$

Множитель $A_T$:

$$
A_T = \begin{cases}
1, & \text{при } p > 100/\cos\theta^{\ast} \\
1.1 \cdot \left(\frac{90 \cdot \sqrt{\cos\theta + 0.001}}{1030}\right)^{\frac{4.5}{p_t \cdot \cos\theta^{\ast}}}, & \text{иначе}
\end{cases}
$$

Здесь:

- $p_w = p_{\text{work}}$ - импульс;
- $p_t$ - модифицированный импульс;
- $r_c = 10^{-4}$ - доля прямых мюонов;
- $\Delta = 2.06 \cdot 10^{-3} \cdot \left(\frac{950}{\cos\theta^*} - 90\right)$ - поправка на потери энергии.

**Свободные параметры:** $A_T$ - нормировка, $\gamma$ - показатель степени.

**Заявленная область:** $p \geq 1$ ГэВ/c, $0^\circ \leq \theta \leq 90^\circ$.

## 3. Шукла

Модифицированный степенной закон по импульсу с угловой зависимостью через эффективную длину пути для сферической Земли.

$$
I(p) = I_0 \cdot N \cdot (E_0 + p)^{-n} \cdot \left(1 + \frac{p}{\varepsilon}\right)^{-1} \cdot D(\theta)^{-(n-1)},
$$

где нормировочный множитель $N = (n - 1) \cdot (E_0 + E_c)^{n-1}$, а геометрический фактор 

$$
D(\theta) = \sqrt{(R/d)^2 \cdot \cos^2\theta + 2 \cdot (R/d) + 1} - (R/d) \cdot \cos\theta
$$

при $R/d = 174$.

- **Свободные параметры:** $I_0$ (нормировка), $n$ (показатель), $E_0$ (параметр потерь)
- **Параметр $\varepsilon$ фиксируется по углу:** $\varepsilon = 854$ ГэВ при $\theta < 75^\circ$; $\varepsilon = 2000$ ГэВ при $\theta \ge 75^\circ$
- **Параметр $E_c$** фиксируется вызывающим кодом на минимальном импульсе выборки.

---

## 4. Рейна

Эмпирическое масштабное соотношение, связывающее угловой и вертикальный спектры: интенсивность при произвольном угле получается из вертикального спектра Бугаева заменой переменной $\zeta = p \cdot \cos\theta$ и домножением на $\cos^3\theta$.

$$
I(p, \theta) = A \cdot \zeta^{-(a_3 \cdot y^3 + a_2 \cdot y^2 + a_1 \cdot y + a_0)} \cdot \cos^3\theta
$$

где $y = \lg\zeta$.

- **Свободные параметры:** $A, a_0, a_1, a_2, a_3$ (всего 5)
- **Заявленная область:** $1 < p < 2000/\cos\theta$ ГэВ/c, $0$ – $90^\circ$
- **Режим `reyna_fixed`:** коэффициенты $a_0 \dots a_3$ фиксируются опубликованными значениями, подгоняется только $A$.
---

## 5. Богданова

Эмпирическая параметризация для широкого диапазона энергий и углов.

$$
I(p, \theta) = \frac{A_0}{p \cdot \cos\theta + 145} \cdot (p + 2.7 \cdot \sec\theta)^{-\gamma} \cdot \frac{p + 5}{p + 5 \cdot \sec\theta}
$$

- **Свободные параметры:** $A_0$ (нормировка), $\gamma$ (показатель)
- **Заявленная область:** $1 \le p \le 10^5$ ГэВ/c, $0$ – $85^\circ$

---

# Метод подгонки

Для каждого набора данных и каждой модели выполняется взвешенная
нелинейная подгонка через:

``` python
scipy.optimize.curve_fit
```

с параметрами:

``` python
sigma = ds["sig"]
absolute_sigma = True
```

и заданными начальными значениями и границами параметров.


Для каждого успешного fit рассчитываются:

$$
\chi^2 = \sum_{i=1}^{N} \left( \frac{I_{\text{data},i} - I_{\text{model},i}}{\sigma_i} \right)^2
$$

и приведённый хи-квадрат $\chi^2/\text{dof}$, где число степеней свободы:

$$
\text{dof} = N_{\text{points}} - N_{\text{parameters}}
$$

Здесь:
- $N$ - число точек данных в выборке
- $I_{\text{data},i}$ - измеренная интенсивность в $i$-й точке (поле `intensity`)
- $I_{\text{model},i}$ - предсказание модели в $i$-й точке
- $\sigma_i$ - полная погрешность интенсивности (поле `total_error`)
- $N_{\text{points}}$ - число точек в наборе
- $N_{\text{parameters}}$ - число свободных параметров модели (2 для Гайссера/Танга/Богдановой, 3 для Шуклы, 5 для Рейны)

Подгонки с `dof < 1` пропускаются.

Если оптимизация не сходится или `χ²` не является конечным числом, набор
также пропускается.

## Основная статистика
 
Файл: `per_dataset_chi2.csv`

Результаты подгонки по каждому набору и каждой модели:

- **название набора** - идентификатор выборки (например, `gaisser_A`, `tang_B85`)
- **угол** - зенитный угол набора данных, градусы
- **число точек** - количество точек данных в наборе, участвующих в подгонке
- **число степеней свободы** - `dof = N - k`, где `N` — число точек, `k` — число свободных параметров модели
- **`χ²`** - хи-квадрат, сумма квадратов нормированных невязок: $\chi^2 = \sum_{i=1}^{N} r_i^2$
- **`χ²/dof`** -приведённый хи-квадрат, критерий качества подгонки 
- **подогнанные параметры** - оптимальные значения свободных параметров модели (например, $A_G$, $\gamma$ для Гайссера)
- **ошибки параметров** - статистические погрешности подогнанных параметров, полученные из ковариационной матрицы
- **невязки** - нормированные разности между экспериментальными данными и моделью: $r_i = (I_{\text{exp},i} - I_{\text{model},i}) / \sigma_i$, где $\sigma_i$ - полная погрешность `total_error` из базы данных

Для каждой из четырёх выборок анализа (`A`, `B`, `B85`, `C`) формируется рейтинг моделей, позволяющий сравнить их качество подгонки в единой системе координат.

Файлы: `ranking_A.csv`, `ranking_B.csv`, `ranking_B85.csv`, `ranking_C.csv`

Для каждой модели рассчитываются следующие агрегированные показатели:

- **число параметров `k`** - количество свободных параметров модели (2 для Гайссера/Танга/Богдановой, 3 для Шуклы, 5 для Рейны, 1 для `reyna_fixed`)
- **число наборов** - сколько экспериментальных наборов данных было использовано для подгонки в данной выборке
- **медиана `χ²/dof`** - медианное значение приведённого хи-квадрата по всем наборам в выборке
- **глобальное `Σχ² / Σdof`** - суммарный хи-квадрат по всем наборам, делённый на суммарное число степеней свободы


Сортировка выполняется по медиане `χ²/dof`.

# Настройки `explore.py`

Основные параметры:

``` python
PLOT_FITS = True
PLOT_PARAMS = True
SHOW_PUBLISHED = True
SCALE_P3 = False
SHOW_PULLS = True
MARK_DOMAIN = True
MAX_FIT_FIGURES = 40
SHOW_WINDOWS = False
SAVE_PNG = True
OUT_DIR = "explore"
DB = "muon_data.db"
```

### `PLOT_FITS`

Строить отдельный график подгонки для каждого набора.

### `PLOT_PARAMS`

Строить общий график параметров против угла.

### `SHOW_PUBLISHED`

Показывать на графиках кривую с опубликованными коэффициентами.

### `SCALE_P3`

Если `True`, вертикальная ось отображает:

``` text
I · p³
```

Это делает степенной спад спектра визуально более удобным для анализа.

### `SHOW_PULLS`

Добавляет нижнюю панель с нормированными невязками:

``` text
(I - I_model) / σ
```

### `MARK_DOMAIN`

Затеняет область за пределами заявленной области применимости модели.

### `MAX_FIT_FIGURES`

Ограничивает число автоматически создаваемых графиков отдельных
подгонок.

# Вывод `explore.py`

Для каждого успешно подогнанного набора печатаются:

-   название;
-   угол;
-   число точек;
-   `χ²/dof`;
-   значения параметров;
-   ошибки параметров.

Пример структуры строки:

``` text
[OK] dataset θ=79.1° n=20 χ²/dof=...
```

Если параметр оказался на границе, выводится предупреждение.

В конце приводится сводка:

-   число успешно подогнанных наборов;
-   число пропущенных наборов;
-   медиана `χ²/dof`;
-   диапазон `χ²/dof`;
-   число наборов с `χ²/dof > 10`;
-   глобальное `Σχ²/Σdof`;
-   медианы и диапазоны параметров;
-   средневзвешенные параметры, когда они согласуются между наборами.
